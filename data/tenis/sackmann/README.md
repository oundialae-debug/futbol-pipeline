# Tennis datasets — archive of Jeff Sackmann's data

[![GitHub](https://img.shields.io/badge/GitHub-mirror-181717?logo=github)](https://github.com/Aneeshers/tennis-sackmann-archive)
[![License: CC BY-NC-SA 4.0](https://img.shields.io/badge/License-CC%20BY--NC--SA%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by-nc-sa/4.0/)

This dataset is an **archival mirror of the public tennis datasets compiled by Jeff Sackmann**.
It exists so the data remains available and citable. It contains **only data and its documentation** —
no models, analysis, or derived code.

A matching mirror lives on GitHub: **https://github.com/Aneeshers/tennis-sackmann-archive**

## Contents

| Folder | What it is | Files | Coverage |
| --- | --- | --- | --- |
| `slam_pointbypoint/` | Point-by-point logs for the four Grand Slams (one `*-points.csv` and one `*-matches.csv` per slam-year), plus `data_dictionary.txt` | 166 CSVs | 2011–2024, all four majors |
| `atp/` | Men's tour: match results, rankings, and player tables, plus `matches_data_dictionary.txt` | 174 CSVs | through 2026 |
| `wta/` | Women's tour: match results, rankings, and player tables | 125 CSVs | through 2026 |

Each folder keeps Jeff Sackmann's original repository README as `UPSTREAM_README.md` for provenance.

## Original sources

- Grand Slam point-by-point — https://github.com/JeffSackmann/tennis_slam_pointbypoint
- ATP — https://github.com/JeffSackmann/tennis_atp
- WTA — https://github.com/JeffSackmann/tennis_wta
